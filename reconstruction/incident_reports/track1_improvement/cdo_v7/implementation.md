# v7 implementation and evidence

The new all-episode runner audits the exact v6 NPZ/GLB pairs for all 30 episodes. It checks rendered depth against a 2.5 m box before processing videos. Each episode is sampled at 33 scored frames; 22 fitting frames select bounded scale factors 0.90–1.10 and camera-ray depth offsets within +/-0.10 m. Translation smoothing is accepted only if fitting silhouette evidence is stable. Eleven disjoint frames check the selected geometry once; a failed held-out trial retains v6. No alternative is selected using held-out results.

Fourteen proposals passed geometry screening. Independent hand review uses the released generalized-winding containment direction, full anatomical hands and a local FPS512 diagnostic, plus unsigned proximity on control-contact-like frames. Failed proposals get one further fitting-only selection among bounded +/-0.06 m depth corrections, followed by disjoint-frame checks. Full actual-mesh hand review, image alignment and common-pixel cached-depth checks cover every scored frame before promotion.

A zero-penetration objective tie was discovered in the first provisional correction run. That run was stopped, its evidence retained under hand_contact_candidates, and a corrected run uses hand_contact_candidates_v2. Feasibility still requires non-increasing penetration and proximity limits; the objective now prefers fitting image overlap among feasible corrections. A real Episode 0 regression verifies that +0.03 m is selected over the first safe -0.06 m option. See selection_regression.json. No submission was made from the stopped run.

Full image review also checks that at most 10% of scored frames lose more than 0.05 IoU. It recomputes common-pixel depth and the original held-out depth checks on the final, hash-bound candidate; it does not assume a later hand correction preserves the first geometry fit. Both diagnostic hand subsets and all human arrays are checked. Host hand roles and hidden alignment remain unavailable; official scores establish final performance.

The validation driver runs GPU stages sequentially, preserves completed evidence, and records full comparison-video decoding. Model/assistant visual inspection remains required before packaging. The official packer validates all 30 pairs, all 60 control hashes, schema, rotations, finite values, mesh geometry and exact human equality. One v7 upload is planned after review.

The constant-depth proposals for Episodes 0 and 26 passed full penetration but failed full-frame proximity. An additional verified-hoop trial targets Episode 0: circular spin/normal-sign transport preserves observed planes, and bounded temporal ray-depth correction jointly constrains full-hand tube clearance and pointwise FPS512 proximity. A radial Hessian bound encloses every mesh face with a second-order interpolation allowance plus 2 mm safety, checked on 830,176 random face witnesses and all face centroids/edge midpoints. Full actual-mesh and image/depth checks remain required; no containment threshold is relaxed. This is direct fitting to predicted hands, not a held-out generalization claim.

Final image review also requires a meaningful retained gain after contact correction: at least 0.005 full-frame IoU improvement, 1 cm common-pixel depth improvement, or 5% surface-motion improvement. A safe correction that undoes the original gain is retained as control.
