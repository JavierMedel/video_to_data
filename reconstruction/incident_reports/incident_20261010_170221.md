### Exact Windows PowerShell commands for later

Run these manually in Windows PowerShell; administrator access may be required to read some channels. They are read-only and do not restart services:

```powershell
$since = (Get-Date).AddHours(-72)
Get-CimInstance Win32_OperatingSystem | Select-Object LastBootUpTime, LocalDateTime
$ids = 17,18,19,20,41,6008,1001
Get-WinEvent -FilterHashtable @{LogName='System'; StartTime=$since; Id=$ids} -ErrorAction SilentlyContinue |
  Sort-Object TimeCreated |
  Select-Object TimeCreated, ProviderName, Id, LevelDisplayName, Message |
  Format-List
Get-WinEvent -FilterHashtable @{LogName='System'; StartTime=$since} -ErrorAction SilentlyContinue |
  Where-Object { $_.ProviderName -match 'Hyper-V|Hypervisor|WHEA|Display|nvlddmkm|Kernel-Power|Disk|stornvme|Ntfs' } |
  Sort-Object TimeCreated |
  Select-Object TimeCreated, ProviderName, Id, LevelDisplayName, Message |
  Format-List
```

Review `C:\Windows\LiveKernelReports` and `C:\Windows\Minidump` metadata locally without copying or uploading dumps. Windows Reliability Monitor (`perfmon /rel`) can help correlate LiveKernelEvent reports.
